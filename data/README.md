# Data

The raw event CSV files used for this project are not included in the public repository.

The notebook expects the following files under `data/raw/`:

- `ggH1000.csv`
- `Diboson.csv`
- `Zjets.csv`
- `Top.csv`

The analysis uses the supplied `FullEventWeight` column when calculating event yields and weighted mass spectra.

The repository does not claim redistribution rights for the original course-provided datasets.
